# 现场实时打分平台 (Live Scoring Platform)

一个为现场评审 / 演出 / 比赛设计的实时打分系统。在同一局域网下，用一台电脑投影**大屏**、手机**扫码打分**、管理员在**后台**配置、**手机控制台**切页，所有数据实时同步。

> 技术栈：Node.js · Express · WebSocket (`ws`) · SQLite (`better-sqlite3`) · `qrcode` · `docx`

---

## ✨ 功能特性

- **四端协同，实时同步**
  - 🖥️ **大屏显示** (`/screen`)：投影端，支持 4 个页面切换 —— 纯背景 / 选手资料 / 打分页 / 排行榜。
  - ⚙️ **管理后台** (`/admin`)：添加选手（名字 + 图片）、评委（名字 + 图片 + 密码 + 专业/大众类型），配置评分规则与背景图。
  - 📱 **评委打分** (`/judge`)：手机扫码进入，数字键盘打分，支持「一人一码」专属直登。
  - 📱 **手机控制台** (`/control`)：扫码进入，切换大屏页面、选择当前选手、开始 / 结束评分、查看评委打分进度。
- **双轨评分**：专业评委分 + 大众评委分，按权重（默认专业 70%）合成最终得分；大众评分默认**关闭**，可在后台开启。
- **评分规则**
  - 大众评分后台开关（默认关）。
  - 可设置「去掉一个最高分和一个最低分」（专业 / 大众分别去极值，≥ 3 人时生效）。
  - 只展示已提交分数的评委；未提交的评委（即便已结束）不显示、也不计入。
- **一人一码**：每位评委生成专属二维码，扫码后只显示自己的账号，避免输错。
- **二维码批量导出**：一键导出 Word（A4 每页 9 宫格），每个二维码下方标注评委名称 + 密码，方便打印分发。
- **重置评分数据**：保留选手与评委名单，仅清空分数并复位评分状态。
- **数据持久化**：所有配置与分数存于 SQLite（`data/pingfen.db`），重启不丢。

## 📦 安装与运行

要求 **Node.js ≥ 16**（依赖 `better-sqlite3` 原生模块）。

```bash
git clone <your-repo-url>
cd pingfen
npm install
npm start
```

启动后控制台会打印当前局域网地址，例如：

```
http://192.168.1.12:3000
```

在**同一 Wi-Fi / 局域网**下，用不同设备打开对应页面：

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 首页导航 | `http://<IP>:3000/` | 四个入口总览 |
| 大屏投影 | `http://<IP>:3000/screen` | 接投影仪 |
| 管理后台 | `http://<IP>:3000/admin` | 电脑端配置 |
| 评委打分 | `http://<IP>:3000/judge` | 手机扫码 |
| 手机控制台 | `http://<IP>:3000/control` | 手机扫码切页 |

> 手机扫码的二维码地址由后台根据当前局域网 IP 自动生成。如果更换网络（例如改用手机热点），请重启服务以重新识别地址，必要时重新导出评委二维码 Word。

## ⚙️ 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口。 |
| `LAN_IP` | 自动检测 | 手动指定对外地址（优先级最高）。当自动识别到虚拟网卡 / 链路本地地址时可用此项覆盖。 |
| `HOST` | 自动检测 | 次优先级的地址覆盖项。 |

示例：

```bash
PORT=8080 LAN_IP=192.168.0.10 npm start
```

## 🚀 使用流程

1. **后台配置**：在 `/admin` 添加选手（名字 + 头像）和评委（名字 + 头像 + 密码 + 类型）。
2. **导出二维码**：在后台导出「评委二维码 Word」，打印分发给评委；或让评委直接扫大屏 / 后台展示的通用码。
3. **控制台准备**：手机打开 `/control`，选择当前选手，切换到「选手资料」页，点「开始评分」。
4. **评委打分**：评委扫码 → 选名字 / 输密码登录（专属码自动登录）→ 数字键盘输入分数 → 提交。
5. **结束与排行**：控制台点「结束评分」，切到「排行榜」页查看最终排名。

## 🔌 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/state` | 获取当前完整状态 |
| `GET` | `/api/info` | 返回局域网 IP / 端口 / 基础地址 |
| `POST` | `/api/judge/login` | 评委登录（名字 + 密码） |
| `POST` | `/api/upload` | 上传头像 / 背景图（base64） |
| `GET` | `/api/qrcode/judge?j=<ID>` | 评委二维码（带 `j` 为专属码） |
| `GET` | `/api/qrcode/control` | 手机控制台二维码 |
| `GET` | `/api/export/judge-qrcodes` | 导出评委二维码 Word（A4 每页 9 个） |

状态同步通过 WebSocket（`/ws`）广播，前端用 `connectState()` 订阅。

## 📝 说明与建议

- **安全性**：本平台面向受信任的局域网现场环境，后台与评委登录未做高强度鉴权。若通过手机热点等开放网络发布，建议为后台增加访问口令。
- **部署到公网**：当前按局域网设计。如需公网访问，请配合反向代理（Nginx/Caddy）并启用 HTTPS，同时注意评委密码等数据的传输安全。
- **数据备份**：`data/pingfen.db` 为唯一数据源，建议定期备份该文件。

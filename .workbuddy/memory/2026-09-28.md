## 数据"每次重启被重置"的真正原因与修复（重要）
- 排查结论：代码里没有 seed。真凶有二：
  1. db.js `migrateIfNeeded()` 的 config.json 自动迁移——db 为空时把旧 `data/config.json` 整体搬进库，表现为"重启后数据被换掉/复活旧数据"。
  2. 此前给的部署命令块含一次性步骤 `rm -f data/pingfen.db`，用户整段复制执行导致每次更新都删库。
- 修复（commit 41d4058）：移除 config.json 迁移逻辑（新库只写默认 meta）；`git rm simulate.js`（演示数据 seeder）；loadState 加启动日志 `[db] 载入数据: 选手X/评委Y/分数Z`。
- 本地 config.json 仍在 data/ 但已不被读取；本地库当前为演示数据（林晓等3选手/4评委/0分数）。
- 待办：用户本地 `git push`（积压 246c247、839225e、41d4058 等），服务器 `git pull && npm install --omit=dev && pm2 restart pingfen`，并删服务器上的 `data/config.json` 防止历史残留混淆。今后更新代码**不要**再执行 `rm -f data/pingfen.db`。
